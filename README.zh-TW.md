# batch-rename-tools（檔名批次工具）

一組獨立的 Python 小腳本，用來批次改檔名與清理檔案。每支腳本都是互動式（會詢問資料夾路徑與選項），只用 Python 標準函式庫。

> **警告：** 這些腳本會真的改名（或刪除）檔案，多數無法復原。使用前請先備份資料夾。

## 腳本說明

- **批量照片檔名按時間命名.py** — 把單一資料夾（不含子資料夾）內的圖片，依「最後修改時間」由舊到新改成連續編號。需輸入起始號碼與位數（例如位數 5 會變成 `00001.jpg`）。支援副檔名：jpg、jpeg、png、bmp、tif、tiff、dng、cr2、arw、nef、webp。改名前會顯示最舊與最新一張，輸入 `y` 才執行；若目標檔名已存在，該檔會被跳過。
- **批量照片檔名按時間命名_由新到舊.py** — 同上，但最新的照片拿到起始號碼、越舊號碼越大。確認時輸入 `y` 開始、`r` 反轉成由舊到新、其他鍵取消。
- **批量檔名加數工具.py** — 針對「主檔名以數字結尾」的檔案，把結尾數字加上指定數值，並保留原本的補零位數（例如 `DJI_0001.JPG` 加 1000 變成 `DJI_1001.JPG`）。資料夾可用第一個命令列參數指定，否則執行時詢問，接著輸入要增加的數字。結尾不是數字的檔案、或新檔名已存在者會被略過；以 `.` 開頭的隱藏檔不處理。沒有確認步驟。
- **檔名長度截斷工具.py** — 掃描資料夾與所有子資料夾，把超過上限的檔名／資料夾名截短（保留副檔名）。預設上限 255（提示中建議加密共用資料夾用 143），可用 UTF-8 位元組（預設）或字元數計算。截斷後撞名會自動加 `~1`、`~2`…。會先列出預覽，輸入 `y` 才改名，並在腳本所在資料夾寫出 CSV 紀錄（`檔名截斷紀錄_<時間>.csv`）。原本是為了 Synology Drive Client 的檔名長度限制而寫。
- **刪除重複檔案.py** — 遞迴刪除檔名結尾為「 - 複製」或「 (數字)」的副本檔，**但只有在同資料夾存在原檔**（去掉後綴、副檔名相同）時才刪。使用 `os.remove` 永久刪除，沒有預覽也沒有確認。

## 需求

- Python 3（只用標準函式庫，不需安裝套件）。
- 以 Windows 為主要使用環境（截斷工具在 Windows 會加 `\\?\` 長路徑前綴）；其他腳本只用一般 `os` 呼叫。

## 使用方式

```
python 批量照片檔名按時間命名.py
python 批量照片檔名按時間命名_由新到舊.py
python 批量檔名加數工具.py [資料夾]
python 檔名長度截斷工具.py
python 刪除重複檔案.py
```

執行後依提示操作；大多數腳本可接受從檔案總管複製、帶引號的路徑。

## 注意事項

- 先備份。改名與刪除都不會自動復原。
- 照片腳本依「最後修改時間」排序，複製檔案可能改變時間，請先看第一張／最後一張的預覽。
- 建議先在資料夾的複本上試跑。
